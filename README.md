Mobile marketplace application for connecting quail breeders with consumers in Morocco.

Quail.ma was developed as an academic mobile-development project at **ENSET Mohammedia**. The goal of the project is to provide a dedicated digital marketplace where breeders can sell quail-related products while customers can easily browse products, place orders, and track their purchases.

**Check out the [PDF Report](rapport_quail_ma.pdf) for more information**
